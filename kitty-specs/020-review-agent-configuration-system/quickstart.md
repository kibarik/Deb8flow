# Quickstart: Review Agent Configuration System

**Feature**: 020-review-agent-configuration-system
**Date**: 2025-02-21

## Basic Usage

### 1. Minimal Configuration

Минимальная конфигурация использует все дефолтные значения:

```yaml
# config/debate_config.yaml
rewrite:
  # Existing settings...
  max_rounds: 5

  # Review agent (minimal)
  review:
    profile: "balanced"
```

### 2. Custom Model Selection

```yaml
rewrite:
  review:
    profile: "balanced"
    llm:
      provider: "anthropic"
      model: "claude-3-5-sonnet-20241022"
      temperature: 0.5
```

### 3. Custom Prompts

```yaml
rewrite:
  review:
    prompts:
      system: "src/prompts/review/custom_system.md"
      user: "src/prompts/review/custom_user.md"
      result_template: "src/prompts/review/custom_template.md"

    prompt_variables:
      project_name: "MyProject"
      team_context: "Frontend team focusing on React"
      coding_standard: "Airbnb Style Guide"
```

### 4. Profile Selection

```yaml
rewrite:
  review:
    # Use strict profile for critical code
    profile: "strict"

    profiles:
      strict:
        llm:
          temperature: 0.1
        checks:
          security: true
          performance: true
          style: true
```

## Common Scenarios

### Security-Only Review

```yaml
rewrite:
  review:
    profile: "balanced"
    checks:
      security: true
      performance: false
      style: false

    prompts:
      system: "src/prompts/review/security_focused.md"
```

### JSON Output for CI/CD

```yaml
rewrite:
  review:
    output:
      format: "json"
      include_snippets: true
      max_comment_length: 200
```

### Strict Review with Timeout

```yaml
rewrite:
  review:
    profile: "strict"
    llm:
      timeout: 60  # Shorter timeout
      max_tokens_response: 1000
    retry:
      max_retries: 1  # Fewer retries
```

### Filtered File Review

```yaml
rewrite:
  review:
    context:
      include_patterns: ["src/**/*.py", "lib/**/*.py"]
      exclude_patterns: ["**/test_*.py", "**/migrations/**/*.py"]
      window_size: 4000
```

## CLI Override Examples

```bash
# Use different profile
debate review --profile lenient

# Override temperature
debate review --temperature 0.3

# Override model
debate review --model gpt-4o --provider openai

# Enable specific checks only
debate review --checks security --checks performance

# JSON output
debate review --output-format json

# Combined overrides
debate review --profile strict --temperature 0.2 --output-format json
```

## Validation

Конфигурация валидируется при загрузке:

```python
from src.rewrite.domain.review_config import ReviewConfig
import yaml

# Load and validate
with open("config/debate_config.yaml") as f:
    config = yaml.safe_load(f)

review_config = ReviewConfig.from_dict(config["rewrite"]["review"])
# Raises ValueError if validation fails
```

## Error Messages

| Error | Message | Fix |
|-------|---------|-----|
| Invalid temperature | `temperature must be between 0.0 and 1.0` | Use value in range |
| Profile not found | `Profile 'xyz' not found. Available: strict, balanced, lenient` | Use valid profile |
| Invalid format | `Invalid format: 'xml'. Must be 'markdown' or 'json'` | Use valid format |
| Prompt file not found | `Prompt file not found: /path/to/file.md` | Create file or fix path |

## Migration from Old Config

Старая конфигурация продолжает работать — новые параметры опциональны:

```yaml
# Before (still works)
rewrite:
  max_rounds: 5

# After (with review config)
rewrite:
  max_rounds: 5
  review:
    profile: "balanced"
    llm:
      temperature: 0.7
```

## Testing Configuration

```python
# Test config loading
def test_review_config_loading():
    config = {
        "llm": {"temperature": 0.5},
        "checks": {"security": True}
    }
    review_config = ReviewConfig.from_dict(config)
    assert review_config.llm.temperature == 0.5

# Test profile merge
def test_profile_merge():
    config = ReviewConfig.from_dict({...})
    merged = config.merge_with_profile("strict")
    assert merged.llm.temperature < config.llm.temperature

# Test CLI override
def test_cli_override():
    config = ReviewConfig.from_dict({...})
    merged = config.merge_with_cli({"llm": {"temperature": 0.1}})
    assert merged.llm.temperature == 0.1
```
