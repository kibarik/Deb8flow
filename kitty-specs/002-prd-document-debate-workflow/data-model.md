# Data Model: PRD Document Debate Workflow

**Feature:** 002-prd-document-debate-workflow
**Date:** 2025-02-13

## Entities

### DocumentInput
Represents an uploaded .docx document for debate analysis.

| Field | Type | Description | Validation |
|--------|------|-------------|------------|
| filepath | str | Path to .docx file on filesystem | Must end with `.docx` extension |
| content_text | str | Extracted text content from document | Non-empty after extraction |
| extracted_at | datetime | Timestamp of text extraction | Set during DocumentTopicNode execution |

### DebateState (Extended)
Extended from existing `debate_state.py` with document support.

| Field | Type | Description | Source |
|--------|------|-------------|--------|
| debate_topic | str | Topic derived from document content | Generated by DocumentTopicNode |
| document_input | str | **NEW** - File path or pre-extracted text | Passed via initial_state |
| positions | Dict[str, str] | PRO/CON position labels | `{"pro": "In favor", "con": "Against"}` |
| messages | List[DebateMessage] | Debate conversation history | Accumulated across stages |
| stage | str | Current debate stage | `opening`, `rebuttal`, `counter`, `final_argument` |
| speaker | str | Current speaker | `pro` or `con` |
| times_pro_fact_checked | int | PRO fact-check failures | Incremented on failed checks |
| times_con_fact_checked | int | CON fact-check failures | Incremented on failed checks |

### DebateMessage
Single message in debate transcript.

| Field | Type | Description |
|--------|------|-------------|
| speaker | str | `pro`, `con`, `judge`, `fact_checker` |
| content | str | Message body text |
| validated | bool | Whether fact-check passed |
| stage | str | Stage when message was created |

### AnalysisResult
Final verdict and assessment from judge.

| Field | Type | Description |
|--------|------|-------------|
| winner | str | `pro` or `con` |
| reasoning | str | Justification for verdict |
| strengths_identified | List[str] | Strengths highlighted by PRO |
| weaknesses_identified | List[str] | Weaknesses highlighted by CON |
| document_viability_assessment | str | **NEW** - Business viability evaluation |

## Relationships

```
DocumentInput --(extracted)--> DocumentTopicNode --(generates)--> DebateState.debate_topic
DocumentInput --(passed via)--> DebateState.document_input
DebateState.debate_topic --(used by)--> ProDebaterNode, ConDebaterNode, JudgeNode
DebateState.messages --(accumulated)--> DebateMessage[]
DebateState --(transitioned by)--> DebateModeratorNode, FactCheckRouterNode
```

## State Transitions

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    DocumentTopicNode                           │
│  Input: document_input (str)                                   │
│  Output: debate_topic, stage="opening", speaker="pro"          │
└───────────────────────┬─────────────────────────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                    ProDebaterNode                            │
│  Input: document_input, debate_topic, opponent_statement      │
│  Output: message with validated=True                          │
└───────────────────────┬─────────────────────────────────────────────┘
                       │
                       ▼
              ┌────────────────────────────────────────────────────────┐
              │           FactCheckNode                      │
              │  Input: last message content                    │
              │  Output: validated flag + failure count          │
              └───────────────┬─────────────────────────────────┘
                             │
                             ▼
                ┌────────────────────────────────────────────────────────────────┐
                │         FactCheckRouterNode / DebateModeratorNode      │
                │  Routes based on validated flag / stage           │
                └───────────────────────┬─────────────────────────────────┘
                                   │
                                   ▼
                         ┌───────────────────────────────────────────────────────────────────┐
                         │              JudgeNode                              │
                         │  Input: debate_topic, debate_history, document_input    │
                         │  Output: winner + reasoning + viability assessment      │
                         └───────────────────────────────────────────────────────────────────┘
```

## Constraints

| Constraint | Description |
|------------|-------------|
| Token limits | LLM context window limits document size |
| File format | Only .docx supported (per spec) |
| Processing time | 5 seconds for document extraction, 3 minutes for full debate |
