# Verification Before Completion Skill

Навык для проверки завершения задачи перед её закрытием.

## Чек-лист верификации:

### 1. Функциональность
- [ ] Задача выполняется как описано
- [ ] Edge cases обработаны
- [ ] Ошибки корректно обрабатываются

### 2. Код
- [ ] Код читаем и понятен
- [ ] Нет дубликации
- [ ] Соблюдены стандарты проекта
- [ ] Нет hardcoded значений

### 3. Тесты
- [ ] Unit тесты написаны
- [ ] Все тесты проходят
- [ ] Покрытие достаточное
- [ ] Edge cases протестированы

### 4. Документация
- [ ] Код задокументирован
- [ ] README обновлен (если нужно)
- [ ] API документация актуальна
- [ ] Примеры использования есть

### 5. Безопасность
- [ ] Нет чувствительных данных в коде
- [ ] Ввод валидируется
- [ ] Права доступа проверяются

### 6. Производительность
- [ ] Нет очевидных узких мест
- [ ] Ресурсы освобождаются
- [ ] Нет memory leaks

## Процесс верификации:

```
1. Self-review
   ↓
2. Автоматические проверки
   ↓
3. Тестирование
   ↓
4. Code review (если применимо)
   ↓
5. Интеграционное тестирование
   ↓
6. Финальная проверка
```

## Команды для проверки:

```bash
# Линтеры
npm run lint
flake8 .
golangci-lint run

# Тесты
npm test
pytest
go test ./...

# Сборка
npm run build
python setup.py build
go build

# Покрытие
npm run coverage
pytest --cov
```

## Критерии готовности (Definition of Done):

- Код слит в main
- Тесты зеленые
- Code review пройден
- Документация обновлена
- В продакшн деплоится
