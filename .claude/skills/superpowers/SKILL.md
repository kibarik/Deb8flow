# Superpowers Skills

Набор навыков для Claude Code, улучшающих продуктивность PM-агента.

## Доступные skills:

- **brainstorming** — генерация идей и мозговой штурм
- **using-git-worktrees** — работа с git worktrees для параллельной разработки
- **writing-plans** — написание планов и спецификаций
- **subagent-driven-development** — разработка через субагентов
- **systematic-debugging** — систематическая отладка
- **test-driven-development** — разработка через тестирование
- **verification-before-completion** — верификация перед завершением

## Использование:

Для активации skill используй:
```
/skill superpowers:<skill_name>
```

Примеры:
```
/skill superpowers:brainstorming
/skill superpowers:writing-plans
```
