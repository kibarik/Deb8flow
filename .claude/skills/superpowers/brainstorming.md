# Brainstorming Skill

Навык для генерации идей и мозгового штурма.

## Процесс:

1. **Сбор контекста**
   - Определи проблему или задачу
   - Собери релевантную информацию
   - Выяви ограничения

2. **Генерация идей**
   - Предложи множество решений без критики
   - Используй аналогии из других областей
   - Комбинируй существующие подходы

3. **Фильтрация**
   - Оцени каждую идею по критериям
   - Отбрось нерабочие варианты
   - Выбери топ-3 перспективных

4. **Детализация**
   - Проработай выбранные идеи
   - Оцени риски и преимущества
   - Составь план реализации

## Техники:

- SCAMPER (Substitute, Combine, Adapt, Modify, Put to other uses, Eliminate, Reverse)
- Mind mapping
- 6 thinking hats
- First principles thinking
