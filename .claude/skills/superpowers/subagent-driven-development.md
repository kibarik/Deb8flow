# Subagent-Driven Development Skill

Навык для разработки через делегирование субагентам.

## Концепция:

PM-агент координирует работу, делегируя задачи специализированным субагентам.

## Типы субагентов:

### 1. Code Agent
- Написание кода
- Рефакторинг
- Исправление багов

### 2. Research Agent
- Поиск информации
- Анализ кодовой базы
- Изучение документации

### 3. Test Agent
- Написание тестов
- Запуск тестов
- Анализ покрытия

### 4. Review Agent
- Code review
- Проверка стандартов
- Аудит безопасности

## Процесс:

```
1. PM анализирует задачу
   ↓
2. Разбивает на подзадачи
   ↓
3. Делегирует субагентам
   ↓
4. Собирает результаты
   ↓
5. Интегрирует и проверяет
```

## Правила делегирования:

1. **Четкая постановка задачи**
   - Что сделать
   - Какие ограничения
   - Критерии успеха

2. **Контекст**
   - Релевантные файлы
   - Связанные задачи
   - История изменений

3. **Верификация**
   - Проверка результатов
   - Тестирование
   - Code review

## Коммуникация:

- Используй структурированный формат
- Указывай приоритеты
- Фиксируй решения
