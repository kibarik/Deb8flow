# Writing Plans Skill

Навык для написания четких планов и спецификаций.

## Структура плана:

### 1. Заголовок
```markdown
# [Название плана]

**Статус:** Draft / In Review / Approved
**Автор:** [Имя]
**Дата:** [YYYY-MM-DD]
```

### 2. Контекст
- Зачем нужен этот план?
- Какую проблему решает?
- Связь с другими планами/задачами

### 3. Цели
- Основная цель (одна)
- Подцели (если применимо)
- Критерии успеха

### 4. Область действия
- Что включено
- Что НЕ включено
- Ограничения

### 5. Детальный план

```markdown
## Этап 1: [Название]
- [ ] Задача 1.1
  - Детали выполнения
  - Ожидаемый результат
- [ ] Задача 1.2
  - ...

## Этап 2: [Название]
...
```

### 6. Риски и митигация
| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| ... | ... | ... | ... |

### 7. Зависимости
- Внешние зависимости
- Внутренние зависимости
- Критический путь

## Советы:

- Пиши атомарные задачи
- Указывай оценки времени
- Определяй ответственных
- Добавляй чекпоинты для проверки
