# Systematic Debugging Skill

Навык для систематической отладки проблем.

## Методология:

### 1. Воспроизведение проблемы
- Опиши точные шаги
- Зафиксируй окружение
- Собери логи/ошибки

### 2. Изоляция
- Сузь область поиска
- Определи компоненты
- Найди минимальный воспроизводимый пример

### 3. Гипотезы
- Сформулируй возможные причины
- Приоритизируй по вероятности
- Планируй проверки

### 4. Проверка
- Одна гипотеза за раз
- Фиксируй результаты
- Обновляй понимание

### 5. Исправление
- Внеси минимальные изменения
- Добавь тесты
- Документируй решение

## Инструменты:

### Логирование
```bash
# Добавь отладочный вывод
echo "DEBUG: variable = $value"

# Используй stderr для отладки
echo "DEBUG" >&2
```

### Git bisect
```bash
git bisect start
git bisect bad HEAD
git bisect good v1.0.0
# Git найдет проблемный коммит
```

### Статический анализ
- Проверь типы
- Найди неиспользуемый код
- Анализируй зависимости
